# Hálózati technológiák
## Szabványügyi szervezetek
- ISOC: Nyílt internet fejlesztése
- IAB: Internet szabványok kezelése, menedzselése
- IETF: Internet, TCP/IP technológia fejlesztése
- IRTF: Internet, TCP/IP hosszútávú fejlesztése
- IANA: kiosztott címek, tartománynevek, portszámokat menedzseli
- IEEE: szabványok
## OSI-modell

| Réteg neve           | Adat neve |
| -------------------- | --------- |
| Alkalmazási réteg    | Data      |
| Megjelenítési réteg  | Data      |
| Viszony réteg        | Data      |
| Szállítási réteg     | Segment   |
| Hálózati réteg       | Packet    |
| Adatkapcsolati réteg | Frame     |
| Fizikai réteg        | Bits      |
### Fizikai réteg
- Meghatározza a fizikai, elektromos tulajdonságokat
- Bitszinten kezeli az adatokat
### Adatkapcsolati réteg
- Két hálózati elem kommunikációja (helyileg)
- Fizikai hibákat jelzi
- Keret szinten kezel adatokat
- MAC-címzés
- Réteghez kapcsolódó eszköz: Switch
### Hálózati réteg
- Globális kommunikáció
- Forgalomirányítást biztosít
- Csomagszintű adatkezelés
- IP-címzés
- Réteghez kapcsolódó eszköz: Router
### Szállítási réteg
- Adatátvitel transzparensége, szegmentálás
- Kapcsolat megbízhatóságát ellenőrzi
- Szegmensszintű adatkezelés
### Viszony réteg
- Szállítási rétegben végpontok közötti kommunikáció kezelése
### Megjelenítési réteg
- Adatok megfelelő konverziója
### Alkalmazási réteg
- Alkalmazások közötti kommunikáció
## TCP/IP Model

| Réteg neve            | Szolgáltatások        |
| --------------------- | --------------------- |
| Alkalmazási réteg     | HTTP, FTP, POP3, IMAP |
| Szállítási réteg      | TCP, UDP              |
| Internet réteg        | IP, ICMP              |
| Hálózat elérési réteg | Ethernet, PPP, HDLC   |
