# Szállítási réteg protokolljai
- Első réteg, ahol a szoftvernek is van szerepe
- Feladata: Adatok továbbítása végponttól végpontig
- Adatokat fogad a viszonyrétegtől, kisebb részekre tördeli, továbbítja a hálózati rétegnek, biztosítja hogy hibátlanul, sorrendben érkezzen
- Létrehozza a hálózati összeköttetést
- Névadási mechanizmus
- Információ áramlási mechanizmussal rendelkezik
- PDU: Szegmens
- IP cím + hozzá kapcsolódó portszám: Socket
## Kezelendő problémák
- Sebesség különbség
- Csomagvesztés
- Duplikáció
- Sorban érkezés garantálása
- Torlódás
- Késleltetett csomagok
- Sérülésmentesség
- Minden fél beleegyezett a kommunikációba
## Szegmentálás
- TH:
	- Forrásport
	- Célport
	- Sorszám
## TCP (Transmission Control Protocol)
- Duplikációt, üzenetidőzítést kezeli
- Visszajelzést kér minden x. adat után a küldés sikerességéről
- Megbízhatóság miatt választjuk
### Fejléc
- Üzenet sorszám, ellenőrző szám
- Control Bits: Üzenet típusa
- Üzenetküldési ablak mérete
### Protokollok
- FTP
- HTTP
- SSH
- SMTP
### Adatküldés folyamata
- Különböző útvonalak használata
- Sorrendberendezés
- Elvesztett csomagok újraküldése
- Az adatoknak sorrendben pontosan kell megérkeznie, sértetlenül
## UDP (User Datagram Protocol)
- Kapcsolatmentes
- Legjobb szándékú
- Közegfüggetlen
- Gyorsaság miatt választjuk
### Fejléc
- Forrásport
- Célport
- Csomaghossz
- Checksum
### Kapcsolódó protokollok
- TFTP
- DNS
- DHCP
- SNMP
### Adatküldés
- Üzenetek sorrendje lényegtelen
- Nem küldi újra az elvesztett üzeneteket
- Különböző útvonalakat választ

## TCP üzenetküldés
- Első üzenet SYN
- Második ACK-SYN
- Harmadik ACK
- Adatfolyam csak ACK-al
- Az első sikertelenül küldött adattól minden adatot újraküld
- SACK: Duplikált üzenetek megoldása
- Lezárás
	- Első üzenet: FIN
	- Második üzenet: ACK, FIN
	- Végül: ACK
## Portszámok kategóriái
- 0-1023: Ismert portok
- 1024-49151: Regisztrált portok (IANA által)
- 49152-65535: Privát, dinamikus portok
