## Maximumkiválasztás és kiválogatás
```
függvény MaximumKiválogatás(x,n)
	y <- Létrehoz(T)[n]
	maxérték <- x[1]
	db <- 1
	y[db] <- 1

	ciklus i <- 2-től n-ig
		ha x[i] > maxérték akkor
			maxérték <- x[i]
			db <- 1
			y[db] <- i
		különben ha x[i] = maxérték akkor
			db <- db + 1
			y[db] <- i
		elágazás vége		
	ciklus vége
	vissza(y,db,maxérték)
függvény vége
```
- Futási idő:
	- n - 1 kiértékelés
	- O(n)
## Kiválogatás és maximumkiválasztás
```
függvény KiválogatásMaximum(x,n,P)
	maxérték <- -inf
	max <- 0
	ciklus i<-1-től n-ig
		ha (P(x[i])) és (x[i]>maxérték)
			maxérték <- x[i]
			max <- i
		elágazás vége
	ciklus vége
	van <- maxérték > -inf
	ha van akkor
		vissza(van,max,maxérték)
	különben
		vissza van
	elágazás vége
függvény vége
```
- Futási idő:
	- n kiértékelés
	- O(n)
