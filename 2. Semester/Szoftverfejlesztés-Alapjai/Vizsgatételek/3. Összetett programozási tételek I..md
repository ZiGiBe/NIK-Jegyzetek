## Másolás
```
függvény Másolás(x, n, f)
	y <- Létrehoz(T)[n]
	ciklus i<-1-től, n-ig
		y[i] = f(x[i])
	ciklus vége
	vissza y
függvény vége
```
- Futási idő: O(n)
## Kiválogatás (külön tömbbe)
```
függvény Kiválogatás(x, n, P)
	y <- Létrehoz(T)[n]
	db <- 0
	ciklus i<-1-től, n-ig
		ha P(x[i]) akkor
			db <- db + 1
			y[db] <- x[i]
	ciklus vége
	vissza(y, db)
függvény vége
```
- Futási idő: O(n)
Kiválogatás (egy tömbbe, felülírva)
```
függvény Kiválogatás(referencia x, n, P)

```
- Futási idő: O(n)
Kiválogatás (egy tömbbe, felülírás nélkül)
```
függvény Kiválogatás(referencia x, n, P)
	db <- 0
	ciklus i<-1-től, n-ig
		ha P(x[i])
			db <- db + 1
			x[db] <->x[i]
		elágazás vége
	ciklus vége
függvény vége
```
- Futási idő: O(n)
