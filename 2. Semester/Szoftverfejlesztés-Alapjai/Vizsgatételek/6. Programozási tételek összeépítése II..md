## Másolás és maximumkiválasztás
```
függvény MásolásMaximum(x, n, f)
	max <- 1
	maxérték <- f(x[1])
	ciklus i<-2-től, n-ig
		segéd <- f(x[i])
		ha maxérték < segéd akkor
			max <- i
			maxérték <- segéd
		elágazás vége
	ciklus vége
	vissza(max, maxérték)
függvény vége
```
## Megszámolás és keresés
```
függvény MegszámolásKeresés(x, n, P, k)
	db <- 0
	i <- 0
	ciklus amíg (i < n) és (db < k)
		i <- i + 1
		ha P(x[i])
			db <- db + 1
		elágazás vége
	ciklus vége
	van <- (db = k)
	ha van akkor
		idx <- i
		vissza(van, i)
	különben
		vissza van
	elágazás vége
függvény vége
```
- Futási idő
	- Legjobb esetben: 0 összehasonlítás (k=0)
	- Legrosszabb esetben: n összehasonlítás
	- Átlagosan: n/2
	- O(n)
