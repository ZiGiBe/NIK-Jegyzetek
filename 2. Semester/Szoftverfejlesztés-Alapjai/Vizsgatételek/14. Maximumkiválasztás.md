## Maximumkiválasztás Rekurzívan
```
függvény FelezőMaximum(x, bal, jobb)
	ha bal = jobb akkor
		vissza bal
	különben
		center <- (bal+jobb)/2
		balmax <- FelezőMaximum(x, bal, center - 1)
		jobbmax <- FelezőMaximum(x, center + 1, jobb)
		ha x[balmax]<x[jobbmax] akkor
			vissza jobbmax
		különben
			vissza balmax
		elágazás vége
	elágazás vége
függvény vége
```
- Futási idő: O(n)
- Hívások száma: 1 + 2 + ... + n/2 + n, ez egy mértani sorozat, melynek kvóciense q=2, így a meghívások összege: 2^(1+log2(n))/2-1, azaz 2(n+1)
## Maximumkiválasztás
```
függvény Maximumkiválasztás(referenciaérték x, n)
	max <- 0
	ciklus i<-2-től, n-ig
		ha x[i]>x[max] akkor
			max <- i
		elágazás vége
	ciklus vége
	vissza max
függvény vége
```
Futási idő: 
- Legrosszabb esetben: n-1-szer fut le
- O(n)
