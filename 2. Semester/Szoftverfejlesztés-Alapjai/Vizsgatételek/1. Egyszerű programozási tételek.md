## Sorozatszámítás
```
függvény Sorozatszámítás(x, n, P)
	sorozat <- 0
	ciklus i<-1-től, n-ig
		sorozat <- sorozat + x[n]
	ciklus vége
	vissza sorozat
függvény vége
```
Futási idő: O(n)
## Eldöntés
```
függvény Eldöntés(x, n, P)
	ciklus amíg (i<=n) és !P(x[i])
		i <- i + 1
	ciklus vége
	van <- (i<=n)
	vissza van
függvény vége
```

## Lineáris keresés
```
függvény LineárisKeresés(referenciaérték x, n, P)
	i <- 1
	ciklus amíg (i<=n) és !P(x[i])
		i <- i + 1
	ciklus vége
	van <- (i<=n)
	ha van akkor
		idx <- i
		vissza(van, idx)
	különben
		vissza van
	elágazás vége
függvény vége
```
Futási idő: O(n)

## Lineáris keresés rendezett tömbben
```pseudocode
függvény LineárisKeresés(x, n, k)
	i <- 1
	ciklus amíg (i<=n) és (x[i] < k)
		i <- i + 1
	ciklus vége
	van <- (i <= n) és x[i] = k
	ha van akkor
		idx <- i
		vissza(van, idx)
	különben
		vissza van
	elágazás vége
függvény vége
```
## Megszámlálás
``` 
függvény Megszámlálás(referenciaérték x, n, P)
	db <- 0
	ciklus i<-1-től, n-ig
		ha P(x[i]) akkor
			db <- db + 1
		elágazás vége
	ciklus vége
	vissza db
függvény vége
```
Futási idő: O(n)
## Maximumkiválasztás
```
függvény Maximumkiválasztás(referenciaérték x, n)
	max <- 0
	ciklus i<-2-től, n-ig
		ha x[i]>x[max] akkor
			max <- i
		elágazás vége
	ciklus vége
	vissza max
függvény vége
```
Futási idő: 
- Legrosszabb esetben: n-1-szer fut le
- O(n)
