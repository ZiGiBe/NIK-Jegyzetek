## Beillesztéses rendezés
```
eljárás BeilesztésesRendezés(referencia x, n)
	ciklus i<-2-től, n-ig
		j <- i - 1
		segéd <- x[i]
		ciklus amíg (j>0) és (x[j] > segéd)
			x[j+1] <- x[j]
			j <- j - 1
		ciklus vége
		x[j+1] <- segéd
	ciklus vége
eljárás vége
```
Összehasonlítások száma:
- Legrosszabb esetben: 2(n-1) + (n(n-1))/2
Futási idő: O(n^2)
## Buborékrendezés
```
eljárás Buborékrendezés(referencia x, n)
	i <- n
	ciklus amíg (i >= 2)
		idx <- 0
		ciklus j<-1-től, i-ig
			ha x[j+1]<x[j] akkor
				x[j+1]<->x[j]
				idx <- j
			elágazás vége
		ciklus vége
		i <- idx
	ciklus vége
eljárás vége
```
Futási idő:
- Legjobb esetben: O(n), ha a tömb eleve rendezve van
- Átlagosan: O(n^2)
## Minimumkiválasztásos rendezés
```
eljárás Minimumkiválaszásos(referencia x, n)
	ciklus i<-1-től, (n-1)-ig
		min <- i
		ciklus j<-(i+1)-től, n-ig
			ha x[min] > x[j] akkor
				min <- j
			elágazás vége
		ciklus vége
		x[i] <-> x[min]
	ciklus vége
eljárás vége
```
Futási idő:
- Összehasonlítások száma: (n*(n-1))/2
- O(n^2)
